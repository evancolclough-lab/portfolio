# 📸 How to Add Images to Your Portfolio

Your portfolio is now set to **Auto-Scan**. You don't need to open any code files to add new work!

## 🚀 Two Steps to Add Work
1. **Prepare your image**: Save your graphic as a `.jpg`, `.png`, or `.webp`.
2. **Name it correctly**: Use the pattern `portfolio-N` (e.g., `portfolio-1.jpg`, `portfolio-2.png`, etc.).
3. **Drop it in**: Copy the file into the `assets/` folder.

## 💡 Important Tips
* **No Gaps**: The website scans in order (1, 2, 3...). If you skip a number (e.g., you have 1 and 3 but no 2), the website might stop scanning at 1. 
* **Supported Formats**: Works with `.jpg`, `.png`, `.jpeg`, and `.webp`.
* **Ordering**: If you want to change the order, just rename the files (e.g., rename `portfolio-5` to `portfolio-1` to move it to the front).
* **Limit**: The scanner is currently set to check for up to 50 images.
